Bienvenido a SES Dashboard

Configura tu dashboard de email en 5 pasos simples

Solo necesitas el dominio, no el email completo

Configura AWS

Conecta tu cuenta de AWS para recibir eventos de email

Pasos para crear usuario IAM:

  1. Ve a AWS IAM Console
  2. Crear usuario → Nombre: ses-dashboard
  3. Adjuntar políticas: AmazonSESFullAccess y AmazonSNSFullAccess
  4. Crear usuario → Guardar Access Key y Secret Key

Verifica tu dominio

Agrega registros DNS para demostrar propiedad del dominio

Agrega estos registros en tu DNS:

TXT
CNAME
CNAME

Configura el Webhook

Recibe notificaciones de email automáticamente

https://tu-dominio.com/api/webhooks/ses

Suscribir SNS Topic:

Ejecuta este comando en AWS CLI:

aws sns subscribe --topic-arn ARN_DEL_TOPIC --protocol https --notification-endpoint https://tu-dominio.com/api/webhooks/ses

Prueba tu configuración

Envía un email de prueba para verificar que todo funciona

Haz clic en "Enviar prueba" para enviar un email de verificación

Esperando evento... 30s

¡Funciona!

Tu dashboard está configurado correctamente
